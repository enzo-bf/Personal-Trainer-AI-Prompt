# 🏋️ Assistente de Personal Trainer com IA

Projeto desenvolvido durante a formação da DIO com foco em Prompt Engineering.

## Objetivo

Criar um assistente inteligente capaz de gerar treinos personalizados com base em:

- Biotipo corporal
- Disponibilidade semanal
- Tipo de exercício preferido

## Tecnologias

- GitHub
- Markdown
- Prompt Engineering
- Inteligência Artificial

## Boas Práticas Utilizadas

- Clareza
- Especificidade
- Contextualização
- Iteração

## Entradas

### Biotipo

- Ectomorfo
- Mesomorfo
- Endomorfo

### Dias por Semana

- 1 dia
- 3 dias
- 5 dias

### Tipo de Treino

- Funcional
- Maquinário
- Peso Livre
- Cardio
- HIIT

## Exemplo

Entrada:

Biotipo: Endomorfo
Dias: 3
Treino: HIIT

Saída:

Treino ABC focado em emagrecimento com exercícios intervalados de alta intensidade e trabalho cardiovascular.

## Aprendizados

Durante este desafio pratiquei:

- Engenharia de Prompt
- Estruturação de instruções para IA
- Contextualização de respostas
- Organização de projetos no GitHub
